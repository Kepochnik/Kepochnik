# FUEL: план запуска

## Идея в одном предложении

Создатель мемкоина заливает ETH в «бак», и все покупки его монеты через FUEL
получают газ обратно в той же транзакции.

## Почему сейчас

- **29 сентября 2026 Robinhood перестаёт платить газ в Robinhood Chain.**
  90 дней весь чейн торговал бесплатно, с этой даты каждая сделка стоит ETH.
- Газ в чейне уже вырастал в 25 раз за 11 дней (Bitquery).
- Больше всех пострадают мелкие покупки на $5–20, а на них держится мемкоин-трейдинг.
- У создателей монет есть ETH: Pons платит им комиссии с каждой сделки. FUEL
  превращает эти комиссии в бесплатный газ для их покупателей.

## Проверка на дубли (26.09.2026)

- **HoodBot**: «без газа» только внутри своего Telegram-бота.
- **Robinhood Wallet**: субсидия заканчивается 29-го.
- **Создатель спонсирует газ покупателям своей монеты**: такого я не нашёл ни на
  GitHub, ни в вебе. Ближайшее — общие paymaster-сервисы ERC-4337 для приложений,
  но они требуют смарт-кошельков и не заточены под монеты.

## Токен $FUEL

Токен вшит в контракт с первого дня:

1. **Буст.** Кошельки, держащие порог $FUEL, получают ×2 дневной лимит возврата
   газа на **всех** баках (`setBoost` в контракте).
2. **Выкуп.** Протокол берёт 2% с каждого пополнения бака (жёсткий потолок в
   контракте — 5%). Казна выкупает $FUEL.
3. **Первый бак — наш.** В день запуска открываем бак для самого $FUEL и
   заливаем туда комиссии создателя. $FUEL — первая монета в чейне, которую
   покупают без газа.

**Запуск:** Pons V2, пара с ETH. Токен сразу можно заправить через FUEL, потому
что v1 поддерживает ETH-кривые Pons.

## Риски

- **Без аудита.** Контракт держит чужой ETH. До крупных баков нужен аудит, на
  старте — лимит на размер бака на сайте.
- **Не проверено на реальном Pons.** Интерфейс взят из открытого исходника Pons V2,
  тесты идут на моках, которые повторяют логику `buy`. Первая реальная покупка в
  мейннете — обязательная проверка.
- **Только кривая.** После выпуска монеты на Uniswap v4 бак больше не работает,
  спонсор забирает остаток через `close`. Поддержка v4 — следующий шаг.
- **Пока покупки только через наш сайт.** Бесплатный газ даёт только покупка
  через FUEL, а не через интерфейс Pons. Поэтому важна интеграция в боты и терминалы.
